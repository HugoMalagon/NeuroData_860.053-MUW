# Lesson 10 - Calcium Imaging: a Group Mini-Project

Apply the tools of Lessons 6-9, in groups, to a new data type: two-photon calcium imaging of neurons responding to tones. Sections 0-2 are done together in class; each group then works on sections A-F and presents its answers at the end of the lesson.

Requires the **Statistics and Machine Learning Toolbox**.

## How to start

1. Download the whole repository (see the main README).
2. In MATLAB, set this folder (`Lesson 10`) as the **Current Folder**.
3. Open `Lesson10_Students.mlx` and run section 0 (Setup).

## Contents

- `Lesson10_Students.mlx` - the project notebook (Live Script)
- `data/` - calcium imaging data (`Calcium_Imaging.mat`) and the tone sequence (`Stimuli.mat`, `Stimuli.csv`); `original/` holds the source files
- `functions/` - helper functions used in the notebook
