# Lesson 9 - Models: Behaviour, Encoding, Decoding and Population Dynamics

Lesson 7 asked "does this neuron respond?". Now we build models: of the animal's choices and learning, of what drives a neuron's firing, and of what the population tells us about the task.

Topics: win-stay / lose-shift, reinforcement learning (Rescorla-Wagner / Q-learning), encoding models, cross-validated decoding, shuffling and bootstrapping, PCA of population activity.

Requires the **Statistics and Machine Learning Toolbox**.

## How to start

1. Download the whole repository (see the main README).
2. In MATLAB, set this folder (`Lesson 9`) as the **Current Folder**.
3. Open `Lesson9_Students.mlx` and run section 0 (Setup and data).

## Contents

- `Lesson9_Students.mlx` - the lesson notebook (Live Script)
- `data/` - spike times and trials of the session, a second session in `OtherSession/`, and a fitted learning model (`RL_Model_PL.mat`)
- `functions/` - helper functions used in the notebook
