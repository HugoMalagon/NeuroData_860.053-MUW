# Lesson 6 - MATLAB for Neuroscience Data

The MATLAB tools you will use in every following lesson, learned directly on real data: 141 neurons recorded in the prelimbic cortex of a mouse performing a gambling task.

Topics: arrays and indexing, logical indexing, loops and conditions, cell arrays, tables, functions, figures, saving results.

## How to start

1. Download the whole repository (see the main README).
2. In MATLAB, set this folder (`Lesson 6`) as the **Current Folder**.
3. Open `Lesson6_Students.mlx` and run section 0 (Setup). It adds the `functions` folder to the MATLAB path.

## Contents

- `Lesson6_Students.mlx` - the lesson notebook (Live Script)
- `data/` - spike time matrix (`STMtx.mat`) and the behavioural trials (`Trials_Sync.mat`, `Trials_Table.mat`, `Trials_Table.csv`)
- `functions/` - helper functions used in the notebook
