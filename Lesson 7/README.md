# Lesson 7 - Spikes and Statistics

Back to the prelimbic-cortex session of Lesson 6 (141 neurons, gambling task): how do single neurons fire, how do they respond to task events, and is the effect real?

Topics: ISI histograms, autocorrelograms and cross-correlograms, rasters and PSTHs, paired and unpaired tests, multiple comparisons (FDR), the unit of observation.

## How to start

1. Download the whole repository (see the main README).
2. In MATLAB, set this folder (`Lesson 7`) as the **Current Folder**.
3. Open `Lesson7_Students.mlx` and run section 0 (Setup and data).

## Contents

- `Lesson7_Students.mlx` - the lesson notebook (Live Script)
- `data/` - spike times and trials of the session (`SpikeTimes.mat`, `STMtx.mat`, `Trials_Sync.mat`, `Trials_Table.mat`); `OtherSession/` holds a second session
- `functions/` - helper functions used in the notebook
