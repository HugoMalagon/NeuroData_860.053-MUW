## Lectures Overview

### Lesson 1

- Introduction to R
- Practical examples: descriptive statistics, t-tests
- Visual analytics with base plots


### Lesson 2

- Introduction to bulk sequencing and analysis methods
- Dimensional reduction: PCA and UMAP
- Clustering methods: k-means, k-NN


### Lesson 3

- Introduction to Seurat
- Preprocessing single-cell RNA-seq data


### Lesson 4

- Understanding and visualizing single-cell expression data (PCA, UMAP, various types of plots)
- Clustering cells in Seurat
- Finding cell types across clusters

### Lesson 5

- Methods for data integration across experiments and batches (batch corrections)
- Differential gene expression (DGE) across genotypes for specific cell clusters
